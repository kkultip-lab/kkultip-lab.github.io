개인정보처리방침 (Privacy Policy)

시행일: 2026-09-28

1. 앱 개요

"알아두면 꿀 업로더"는 채널 운영자 본인만 사용하는 개인용 도구로, YouTube API Services를 사용합니다. 이 앱을 사용하면 YouTube 서비스 약관에 동의하는 것이며, Google의 개인정보 처리는 Google 개인정보처리방침을 따릅니다.

2. 접근하는 정보

  • youtube.upload — 본인이 만든 영상을 본인 채널에 업로드
  • youtube.readonly — 본인 채널의 영상 목록과 상태 확인
  • yt-analytics.readonly — 본인 채널의 조회수·시청 지속률 등 통계 확인

3. 저장과 공유

OAuth 토큰과 통계 데이터는 운영자의 개인 PC에만 저장됩니다. 외부 서버로 전송하거나 제3자에게 공유·판매하지 않습니다. Google 사용자 데이터는 위 기능 외의 목적으로 사용하지 않으며, 광고나 AI 모델 학습에 사용하지 않습니다. 이 앱의 Google API 사용은 Google API Services User Data Policy(Limited Use 요건 포함)를 준수합니다.

4. 삭제와 권한 철회

로컬에 저장된 토큰과 데이터는 운영자가 언제든 삭제할 수 있으며, Google 계정 권한 페이지나 Google 보안 설정에서 앱의 접근 권한을 철회할 수 있습니다.
